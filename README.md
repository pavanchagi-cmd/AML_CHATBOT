# AML Compass

A RAG web app where new L1/L2 AML analysts ask questions and get answers drawn only from uploaded documents, with a citation for every point. Built with Next.js on Vercel, Google Gemini (embeddings and answers), Pinecone (vector search), Neon Postgres and Vercel Blob.

Work in progress. Full setup, seeding and deployment instructions will be added in build step 7.

## Local development

```bash
cp .env.example .env.local
npm install
npm run dev
```
